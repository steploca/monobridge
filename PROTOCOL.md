# Monogram Core v2 serial protocol (community notes)

These are independent interoperability notes about how the Monogram Creative Console Core talks to a computer. They are not official documentation.

## Transport
- USB CDC serial device, VID `0x0483` / PID `0xA2C5` (shows up as `/dev/cu.usbmodem*` on macOS)
- 300000 baud
- Only one program can hold the port, so quit Monogram Creator / Monogram Service first

## Framing
- Each message is a **MessagePack** map
- Each frame starts and ends with `0x7E`
- Any `0x7E` or `0x7D` byte inside the payload is sent as `0x7D` followed by `byte XOR 0x20` (HDLC-style escaping)

## Host → Core
| Message | Purpose |
|---|---|
| `{get_version: true}` | Core replies with `version_core`, `build_info`, `mcu_uid`, ... |
| `{get_layout: true}` | Core replies with the module tree `l` |
| `{get_check: true}` | Keepalive, sent every few seconds. Core replies `l_time`; if it changed, re-request the layout |
| `{get_state: <localId>}` | Asks for one module's current values |
| `{set_module: [localId, 0x02, r \| g<<8 \| b<<16]}` | Sets a module's LED colour |
| `{set_module: [localId, 0x05, rgb \| sub<<24]}` | Sets a sub-module LED on 3x modules; commit with `rgb = 0x7F<<24` |
| `{set_brightness: [moduleLed, displayBacklight]}` | Sets LED and display brightness |
| `{add_action: [id, [10 bytes]]}` / `{clear_action: id}` | Core-side USB actions: MIDI, keyboard, mouse or joystick generated by the Core firmware itself |
| `{write_display_slow: [true, 0, y0, 240, y1, rgb565]}` | Writes rows to the 240×240 screen; surround with `{invoke_display: 3}` (off) and `{invoke_display: 4}` (on) |

## Core → Host
- `l`: layout tree. Each node is `{i: localId, t: typeId, u: uuid, c: [children]}`
- `l_time`: layout timestamp
- `in`: list of `{i: localId, v: [bytes]}` input events. Entries may be null (padding)
- `in_noop`: the same shape as `in`, but a status refresh rather than user action
- `err`: firmware error code. The low byte is the error, e.g. 250 = module not responding on I²C

## Type IDs and input values (`v`)
| typeId | Module | `v` |
|---|---|---|
| 0, 128, 25 | Core | – |
| 1, 129 | Button | `[pressed]` |
| 2, 130 | Dial | `[pressed, ccwTicks, cwTicks, absPos, signedTicks, tapped]` (96 ticks/turn) |
| 3, 131 | Slider | `[pos 0–255]` |
| 8 | 3× Button | `[bitmask]` |
| 9 | 3× Dial | `[pressMask (bits 0-2) / tapMask (bits 4-6), t1, t2, t3]`, ticks as signed int8 |
| 10 | 3× Slider | `[_, p1, p2, p3]` |
| 24 | Orbiter | `[turn, BxHi, BxLo, ByHi, ByLo, x_i8, y_i8]` |
| 20, 21 | Falcon mini | not yet decoded |
